## 👤 About Me 

I'm Faneva (Faneva-P15), a computer science student at ENI Fianarantsoa, Madagascar.

I have a genuine interest in system and network administration. I want to progress and develop my skills every day by learning new tools and taking on technical challenges.

I like to understand how things work, and I'm ready to invest myself to carry out the missions entrusted to me.

> Collecting logs, securing servers and watching dashboards: that's my kind of fun.

- 🔧 **Currently working on:** internship as a system and network administrator at Nextidea Company
- 📚 **Currently learning:** Docker, ELK Stack, Prometheus, Grafana, Loki and Alertmanager
- 🧪 **Past projects:**
  - Secure and monitored Docker infrastructure to host Odoo
  - Centralized logs with the ELK Stack
  - Website moved from HTTP to HTTPS with Nginx
  - Virtual network with pfSense and two VLANs
- 🌍 **Languages I speak:** Malagasy, French, English
- 🎓 **Education:** Bachelor's degree in Computer Science, ENI Fianarantsoa
- 🎯 **Interests:** Reading, singing, anime
